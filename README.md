## ✨ SonicWave چیست؟

**SonicWave** یک موزیک‌پلیر مدرن و چندسکویی است که با **Flutter** ساخته شده و روی **اندروید 7+** و **ویندوز 7+** اجرا می‌شود. با رابط کاربری تاریک/روشن، 8 تم رنگی، متن آهنگ زنده، صف پخش هوشمند و به‌روزرسانی خودکار، تجربه‌ای در حد پلیرهای حرفه‌ای ارائه می‌دهد.

---

## 🎧 قابلیت‌های پخش

| قابلیت | توضیح |
|---|---|
| 🔄 **صف پخش هوشمند** | افزودن، حذف و جابه‌جایی آهنگ‌ها در حین پخش |
| 🔀 **پخش تصادفی و تکرار** | حالت‌های Off / All / One + شافل هوشمند بدون تکرار |
| ⚡ **سرعت پخش** | از 0.5x تا 2x به صورت زنده |
| 🔊 **ولوم و Mute** | اسلایدر ولوم با ذخیره‌سازی دائمی |
| ⏰ **تایمر خواب** | 5 / 15 / 30 / 60 دقیقه با محو تدریجی صدا |
| 🎯 **دکمه قبلی هوشمند** | اگر بیش از 3 ثانیه گذشته، از اول پخش می‌کند |
| 💾 **ادامه پخش** | آخرین آهنگ و دقیقاً همان ثانیه، بعد از باز شدن اپ |
| 📢 **پخش در پس‌زمینه** | با نوتیفیکیشن و کنترل کامل (اندروید) |
| 🎹 **کلیدهای رسانه** | پشتیبانی از Media Keys ویندوز و هدفون |

## 📝 متن آهنگ (Lyrics)

- 🔎 **دریافت خودکار** متن هماهنگ‌شده از سرویس LRCLIB
- 📄 **فایل‌های محلی** `.lrc` و `.txt` کنار آهنگ
- 🎤 **حالت کاراوکه** — هایلایت خط‌به‌خط با اسکرول خودکار
- ✍️ **افزودن دستی** — متن خودت را paste کن، برای همیشه ذخیره می‌شود
